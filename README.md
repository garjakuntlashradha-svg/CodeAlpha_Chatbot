CodeAlpha Offline Chatbot

Project Description

An offline, rule-based conversational chatbot developed using Python for the CodeAlpha Python Programming Internship.

Features

- Multiple conversational topics
- Randomized responses
- Basic conversation memory
- Time and date responses
- Study, hobby, and motivation conversations
- No internet connection or external libraries required

Technologies

- Python
- Visual Studio Code

How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run "python chatbot.py".

Concepts Learned

Functions, loops, conditional statements, lists, dictionaries, regular expressions, and string processing.
